Audit log 0

1. Source of record changesA change from the system that owns a fact is applied right away and logged with its source.
2. Rules handle the arithmeticFacts that are pure math on another fact update themselves. No one needs to approve "3 days after".
3. People own the decisionsWhen a change breaks a decision, it goes to that decision's owner with the reason and clear options. Agent guesses wait for them too.
What this demo leaves out. The links between facts are set by hand here. In a real team, finding those links automatically from tickets, docs and chat is the hard part, and so is deciding which source is the record for each fact.
